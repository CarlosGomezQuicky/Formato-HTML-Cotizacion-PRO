# Formato-HTML-Cotizacion-PRO
Repositorio de practica con el  fin de compartir conocimiento y practica para 
# Formato HTML Cotización PRO

Plantilla HTML para la generación y presentación de cotizaciones de CONTPAQi Comercial PRO.

## Objetivo

Desarrollar y mantener un formato HTML que permita presentar cotizaciones de manera profesional y organizada.

## Características

- Plantilla desarrollada exclusivamente en HTML.
- Diseño para cotizaciones de Comercial PRO.
- Archivo editable y versionado mediante Git.
